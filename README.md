# holbertonschool-modern_ai

Holberton School Modern AI / Machine Learning curriculum projects.

## Structure

| Directory | Project |
| --- | --- |
| [`math/linear_algebra`](math/linear_algebra) | Linear algebra with Python and NumPy |
| [`math/plotting`](math/plotting) | Plotting with Matplotlib |
| [`math/probability`](math/probability) | Probability distributions |
| [`pipeline/pandas`](pipeline/pandas) | Data manipulation with Pandas |
| [`pipeline/apis`](pipeline/apis) | Data collection from APIs |
| [`data_analysis/web_scraping`](data_analysis/web_scraping) | Web scraping |
| [`data_analysis/data_preparation_visualization`](data_analysis/data_preparation_visualization) | Data preparation and visualization |
| [`machine_learning/linear_models`](machine_learning/linear_models) | Linear models with Scikit-learn |

## Requirements

- Ubuntu 20.04 LTS, Python 3.11
- Code style: `pycodestyle` 2.14.0
